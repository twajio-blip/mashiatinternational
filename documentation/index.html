Step 2: Open the Project

Navigate to the project folder and open the index.html file in your code editor.

Step 3: Verify Tailwind CSS

The project uses Tailwind CSS via a CDN link. Ensure the following line is present in the <head> section of your index.html:

    <link href="https://cdn.jsdelivr.net/npm/tailwindcss@2.2.19/dist/tailwind.min.css" rel="stylesheet">

This link ensures Tailwind CSS is loaded and ready to style your website.

Step 4: Verify jQuery

The project also includes jQuery for dynamic interactions. Verify the following script tag is included at the end of the <body> section:

    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>

This link loads the jQuery library into your project.

Step 5: Open the Project in a Browser

Use any browser to view the website:

  • Open the index.html file directly in the browser.
  • Alternatively, use a local server for development:
    # If you have Python installed, run:
    python -m http.server

Step 6: Customization

To modify or add features:

  • Edit the HTML files to update content and structure.
  • Customize the design by adding or updating Tailwind CSS classes in your HTML elements.
  • Enhance interactivity by adding custom JavaScript/jQuery code in the provided script.js file or directly in your HTML.
